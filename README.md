## 🎯 Course Objective

The course aims to provide an understanding of analyzing algorithms and their complexity. It allows the development of data structures including Abstract Data Types, Linked Lists, Stacks, Queues, Trees, and Graphs using the C++ programming language. 

Additionally, mathematical techniques are used to analyze the efficiency of various algorithms presented, as well as common operations on the data structures discussed. Students implement algorithms and conduct real-system performance measurements and analyses using C++. This course aims to contribute towards the attainment of **SDG 9 – Industry, Innovation, and Infrastructure**.
